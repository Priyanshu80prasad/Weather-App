# Weather App

An Android weather app built with Kotlin that shows live weather
for the user's current location or any searched city.

## Features
- Auto-detects current location (Fused Location Provider)
- Search weather of any city (Open-Meteo Geocoding API)
- Shows temperature, feels like, humidity, wind speed,
  daily high/low, sunrise and sunset
- Handles runtime permissions and API errors

## Tech Stack
Kotlin, Retrofit, Gson, Kotlin Coroutines, ViewBinding,
Google Play Services Location, Open-Meteo API
